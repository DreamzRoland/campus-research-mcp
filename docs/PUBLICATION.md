# Public distribution and privacy scope

This publication is a fresh source snapshot, not a push of the original private
development repository or its Git history. It includes original project code,
offline tests, generic deployment templates and public documentation.

Excluded: API keys, tokens, SSH configuration, private proxy bootstrap code,
actual server addresses and aliases, organization/workspace/Tunnel/Space IDs,
personal filesystem paths, private deployment and verification logs, databases,
harvest state, downloaded literature, screenshots and historical patch scripts.

The public example alias is research-host. Loopback addresses and synthetic
security-test fixtures remain intentionally: they are not deployment addresses.
The Git commit uses a GitHub noreply email, not a personal email address.

Publisher URLs, public paper identifiers, standard API endpoints, generic service
names and cache paths remain because they describe the software. Keys and access
permissions must be supplied and independently verified by each deployer.

MIT covers the project code only. Dependencies keep their own licenses; no
publisher full text, paid access entitlement or third-party API permission is
redistributed. No original third-party downloader package is vendored.
